# Excel Dashboard

## Project Overview

The **Pranali Excel Dashboard** is an Excel-based data analysis and business intelligence project designed to analyze sales performance, profit, regional 
performance, and product categories.

This project uses Excel formulas, summary tables, and a business performance dashboard to convert raw sales data into meaningful insights that support better 
business decision-making.

## Project Objectives

- Analyze sales and profit performance.
- Compare sales across different regions.
- Evaluate product category performance.
- Use advanced Excel formulas to retrieve order information.
- Create summarized reports from raw sales data.
- Develop a business performance dashboard.

## Project Structure

The Excel workbook contains four worksheets:

### 1. Raw_Data
Contains the original sales dataset with 100 sales records and 14 columns, including:

- Order ID
- Order Date
- Customer Name
- City and Region
- Product Category and Product Name
- Sales Representative
- Units Sold
- Unit Price
- Total Sales
- Discount Percentage
- Profit
- Profit Status

### 2. Pivot_Tables
Contains summarized sales and profit reports.

- Regional Sales & Profit Summary
- Category Sales & Profit Summary

These summaries help compare business performance across regions and product categories.

### 3. Advanced_Formulas
Demonstrates advanced Excel formulas for searching and analyzing order information.

- **VLOOKUP:** Retrieves customer details, region, product category, sales, and profit.
- **INDEX-MATCH:** Finds the city associated with a selected order.
- **Nested IF:** Classifies profit into High Margin, Standard Margin, or Low Margin.
- **Order ID Lookup:** Allows users to change the Order ID and retrieve related information.

### 4. Dashboard
Provides an executive business performance dashboard with key performance indicators (KPIs):

- Total Sales
- Total Profit
- Total Orders
- Average Order Value

The dashboard provides a quick overview of overall business performance.

## How to Use

1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. Visit the `Raw_Data` worksheet to explore the dataset.
4. Open `Pivot_Tables` to review sales and profit summaries.
5. Navigate to `Advanced_Formulas` and enter an Order ID in the lookup cell to retrieve order details.
6. Open `Dashboard` to review the main business performance indicators.

**Note:** Keep the raw data structure consistent when editing the workbook so that the formulas and summaries continue to work correctly.
